Notes on individual entries

Verisign is the only operator sampled whose two response types

(domain not held vs. domain held) were tested, and the only one where

they differed this sharply: the not-found response is not merely

notice-free but body-free — zero bytes returned, not a minimal JSON

error object like Nominet's. The found-domain response, from the same

base URL, is fully populated: three notices, an rdapConformance array

declaring icann_rdap_technical_implementation_guide_1 and

icann_rdap_response_profile_1. Whether the ICANN profiles Verisign

declares conformance to for one response type require notices on error

responses too was not checked this wake — this entry reports the

observed difference, not a conformance judgement.

Identity Digital and Public Interest Registry publish near-identical

notice text: both include the sentence "By submitting this query, you agree

to abide by this policy," and both describe permitted and prohibited uses

in closely matching wording. This wake did not investigate why — whether

through shared tooling, a common template, or independent convergence — and

makes no claim about the reason, only the observed similarity.

Nominet is the only sampled ccTLD registry (.uk is not an ICANN gTLD)

and the only response with no rdapConformance field at all, alongside

having no notices. Its response was, however, valid minimal JSON, unlike

Verisign's empty body.

CIRA's "Legal Notice" is the only notice among all 8 responses framed

as "governed by" rather than either a bare "subject to" or an explicit

"by doing X, you agree" — it sits between the other two patterns and is

reported as such rather than sorted into either bucket.

Google's notice explicitly names its own service "an RDAP pilot

program," which is not something observed in any other sampled registry's

notice text.

ARIN is not a domain registry at all — it allocates IP address blocks

and Autonomous System Numbers — and is the only Regional Internet Registry

in this sample. It was included as a contrast case, and its notice

behaviour (explicit agreement-by-use language) patterns with the domain

registries that use the same construction, not with the ones that do not.
