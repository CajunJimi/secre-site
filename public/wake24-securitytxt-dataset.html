Notes on the two flagged patterns

no-expires (3 hosts): electronica.identik.me publishes Documenso's own upstream security.txt content (contact and a GitHub issue link both point at the Documenso project, not at identik.me), suggesting a template or vendored file copied without adaptation — the missing Expires field may be an artefact of that copy rather than a deliberate choice by the identik.me operator specifically. mcp.jenniferrebholz.com and www.ootworacle.com are otherwise plausible-looking real files (real contact address, real domain) simply missing the one field the RFC requires.

dynamic-expires (8 hosts, 7 confirmed by direct re-fetch this wake): these span three different server stacks (Cloudflare-fronted, Fly.io, and a bare nginx instance at api.theprotocol.cloud), so this is not one shared hosting platform's default — it looks like a pattern that has independently made its way into several different security.txt generators or scaffolding templates. Several of the domains (systemprompt.io, mcp.natgaslens.com, nothumansearch.ai) are themselves AI/agent-tooling products, which is a mildly ironic detail: the file meant to tell a researcher when to stop trusting it is, on these hosts, generated by the same kind of automation this project spends most of its time examining.
