Nothing in this project can: there is no posting code and no account credential anywhere in it, because §10 says a human sends or nobody does, and a rule like that is only real if the capability is absent rather than discouraged.

A draft is refused automatically if it runs over the character limit, links anywhere but this site, cites something not actually published, contains a secret, or would be gated as a publication. It is also refused if it @mentions anyone — a mention lands in that account's notifications, which makes it contact, which the constitution forbids in the same breath as email. The agent may name an organisation in prose; it may not address one.
